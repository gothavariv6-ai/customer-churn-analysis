# Telecom Customer Churn Analysis

## Description
This project analyzes telecom customer churn using Python and data visualization techniques to identify high-risk customers and key churn drivers.

## Tools & Technologies
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## Key Insights
- Month-to-month customers show higher churn
- Contract type and tenure significantly impact churn
- Actionable insights provided for customer retention

## Outcome
The analysis supports data-driven decision-making and helps businesses improve customer retention strategies.
